# Asten 0.0.1b (pre-alpha)

The second public build of Asten, a writing desk that keeps the facts of your
story and marks in red where the page contradicts them. It never writes your
prose. This is a pre-alpha: expect rough edges and changes to the file format
before 1.0.

0.0.1b makes the desktop app complete, standalone software: install it, write,
check, version, import, export, back up, and, if you choose, ask an assistant
that uses a model you picked. Everything works offline except the assistant's
calls to the provider you chose.

## What is new

- **An assistant that uses your own key.** Optional, off by default. It
  explains a mark, searches your canon, summarises a source and proposes a fact
  for you to confirm. It never writes, rewrites or continues your prose and has
  no tool that edits your manuscript. Providers: OpenAI, Anthropic, Google
  Gemini, Mistral, DeepSeek, Qwen, Kimi, GLM, Ollama on your own machine, or any
  OpenAI-compatible address you enter. Keys live in your operating system's
  credential store (or an encrypted file) and never reach the page. Consent is
  per provider and tied to its address; a spend cap of zero means no call;
  offline mode allows only a model on your own machine; and you can read the
  exact request, with your key shown as a placeholder, before it is sent.
  Manuscript wording is left out unless you pick a passage. What is sent, when,
  and to whom: [the AI policy](https://asten-writing.vercel.app/ai-policy) and
  [the privacy notice](https://asten-writing.vercel.app/privacy#the-assistant).
- **Importers that read structure.** Word (.docx) with tracked changes and
  comments, Markdown, HTML and plain text keep their headings, emphasis, lists
  and quotes. A long file with chapter headings arrives as a manuscript with a
  document per chapter. Compile writes the same formatting back out: Word with
  real styles and revisions, HTML with its emphasis.
- **A project file.** Save a project as one `.asten` file and open it as a new
  project on another computer.
- **Backups and restore.** The library is backed up when Asten opens and on
  demand; save a copy anywhere; restore one (the library it replaces is kept).
  Rename and delete projects.
- **Asten's own icon everywhere.** The desktop app, the installer and
  uninstaller, the web app, the favicon and the Word add-in now carry the
  Palette mark. They had been a placeholder.
- **Acceptance runs on the real window.** The scripts in `tools/acceptance/`
  drive the installed app on a scratch profile; results are in
  `docs/ACCEPTANCE-0.0.1b.md`.

## Two ways to try it

- **Desktop (Windows x64, Linux x64).** The app runs the Asten engine and API
  on your machine, with your manuscript in one SQLite file in your
  application-data folder. On first start, choose **Open the sample novel** to
  see the engine at work, or create your own project.
- **In the browser:** <https://asten.103.191.50.32.sslip.io/>. The hosted
  pre-alpha still runs release 0.0.1a and has no assistant: it calls no AI
  provider. It is for trying Asten, not for your manuscript; the sandbox is
  deleted 24 hours after your first visit.

## Install

- **Windows:** run `Asten_0.0.1-beta_x64-setup.exe` (it installs for your user
  only), or unzip the portable build and run `Asten.exe`. The builds are not
  code-signed: SmartScreen shows "Windows protected your PC"; choose **More
  info**, then **Run anyway**, after checking the SHA-256 below.
- **Linux:** make the AppImage executable (`chmod +x`) and run it (it needs
  FUSE 2: `sudo apt install libfuse2`, or run it with
  `--appimage-extract-and-run`), or install the .deb with
  `sudo apt install ./Asten_0.0.1-beta_amd64.deb`. Needs glibc 2.35 or newer and
  WebKitGTK 4.1 (Ubuntu 22.04, Debian 12 or newer).
- **Updating from 0.0.1a:** Settings, Continuity checks, This desk, **Check for
  updates** asks for a newer release only when you press it and installs only
  after a second press. Nothing checks on its own. The .deb updates through
  your package manager.

## What works

- The manuscript editor with the binder, comments, find, page view and tracked
  changes; autosave on every pause.
- The canon engine: facts settled or proposed, the Scales, fifteen rules in
  seven families, marks that explain themselves, repairs you choose,
  suppressions and baselines.
- Cast, timeline, world board and the knowledge view with its graph.
- History: snapshots, verify, blame, drafts and merge.
- Compile to Markdown, plain text, Fountain, HTML, DOCX, EPUB 3 and Final Draft
  (.fdx); import of all but EPUB.
- Settings, keybindings, themes, the command palette and the console.
- Word and Google Docs guests pair with the desktop app over loopback.
- `asten-api`, the local API and engine without the window, for both platforms.

## Known limits

- The assistant's provider adapters were tested against mock servers that speak
  each vendor's wire format, in the real window with the real credential
  store. They have not been run against the live services; a live call needs
  your key. Treat the first call to each provider as the real test.
- The builds are not code-signed (see Install).
- Windows needs the Microsoft Edge WebView2 runtime (part of Windows 10 and 11);
  the installer fetches it if missing. The portable zip does not.
- On Linux the window needs WebKitGTK 4.1. Under a virtual display or a driver
  without hardware acceleration, start it with
  `WEBKIT_DISABLE_COMPOSITING_MODE=1 WEBKIT_DISABLE_DMABUF_RENDERER=1`.
- The Word task pane is tested in a browser with a stand-in for Office.js (no
  Word was available), and needs HTTPS on `localhost:3000`; Word for Mac
  (Safari's engine) may refuse an https page calling the loopback API.
- A pronoun on its own is not resolved to a name (D15), and brown against green
  eyes is not raised because the colour lattice treats hazel as a neighbour of
  both.
- Web sign-in: not applicable. Asten has no accounts by design; guests pair
  with a six-digit code.
- Word files: pictures, footnotes, headers and footers and text boxes are not
  imported.
