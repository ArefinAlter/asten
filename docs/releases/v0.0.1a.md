# Asten 0.0.1a (pre-alpha)

The first public build of Asten, a writing desk that keeps the facts of your
story and marks in red where the page contradicts them. It never writes your
prose. This is a pre-alpha: expect rough edges and changes to the file format
before 1.0.

## Two ways to try it

- **Desktop (Windows x64, Linux x64).** The app runs the Asten engine and API
  on your machine, with your manuscript in one SQLite file in your
  application-data folder. Nothing is sent anywhere. On first start, choose
  **Open the sample novel** to see the engine at work on a short story written
  for Asten, or create your own project.
- **In the browser:** <https://asten.103.191.50.32.sslip.io/>. The same
  workbench and the same engine, running on Verne's server in a private
  sandbox for each visitor. The sandbox and everything in it are deleted 24
  hours after your first visit. It is for trying Asten, not for your
  manuscript.

## What works

- The manuscript editor with the binder, comments, find, page view and
  tracked changes.
- The canon engine: facts settled or proposed, the Scales, seventeen rules in
  seven families, marks that explain themselves, repairs you choose,
  suppressions and baselines.
- Cast, timeline, world board and the knowledge view with its graph.
- History: snapshots, verify, blame, drafts and merge.
- Compile to Markdown, plain text, Fountain, HTML, DOCX, EPUB 3 and Final
  Draft (.fdx); import of all but EPUB.
- Settings, keybindings, themes, the command palette and the console.
- The assistant panel runs Asten's own tools under fixed rules. AI providers
  can be configured but none is called in this release, and the assistant
  never writes prose.
- Word and Google Docs guests pair with the desktop app.
- `asten-api`, the local API and engine without the window, for both
  platforms.

## Planned

- Signed installers, macOS, Windows ARM64 and Linux aarch64 builds.
- Phone shells after device testing.
- Local perception models that only propose (never generate).

## Known issues

- The builds are not code-signed. Windows SmartScreen warns before the first
  run: choose **More info**, then **Run anyway**. On Linux, make the AppImage
  executable (`chmod +x`) or install the .deb with `sudo apt install ./…deb`.
- Windows needs the Microsoft Edge WebView2 runtime (part of Windows 10 and
  11); the installer fetches it if missing. The portable zip does not.
- Settings → This desk → Check for updates reads
  `https://asten-writing.vercel.app/updates/latest.json` only when pressed.
  The .deb updates through your package manager, not the app.
- The hosted copy cannot be paired with the Word or Docs guests.
